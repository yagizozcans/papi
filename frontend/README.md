# papi frontend

React 19 + TypeScript + Vite + Tailwind v4 + shadcn/ui dashboard for papi. Spec: `docs/prd/14-frontend.md`.
Served by FastAPI at `/app/`. No external requests at runtime (fonts are self-hosted).

## Develop (with a running papi)

```sh
cd frontend
npm ci
npm run dev          # http://localhost:5173/app/ ; /v1 is proxied to http://127.0.0.1:38417
```

Start papi first (it listens on 127.0.0.1:38417). The dev proxy rewrites the `Origin` header so POST requests pass papi's same-origin check.
On a LAN bind, open the URL once with `?token=...` so the cookie is set.

## Build

```sh
npm run build        # tsc -b && vite build -> ../src/papi/web/ui/ (git-ignored)
```

Other scripts: `npm run typecheck`, `npm run lint`, `npm test`.

## Regenerate API types

```sh
npm run gen:api      # dumps papi's OpenAPI to src/api/openapi.json, then generates src/api/schema.d.ts
```

`npm run gen:api:local` only regenerates `schema.d.ts` from the checked-in `openapi.json`.
`src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin on `dev`/`build`; commit it.
